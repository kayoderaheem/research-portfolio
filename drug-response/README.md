# Drug Response Research Intelligence

This workspace tracks the computational frontier in cancer drug response, perturbation biology, virtual-cell modeling, and treatment-response translation.

The goal is not to collect papers. The goal is to convert external advances into testable biological research questions and reproducible publication projects.

## Research question

How can computational models predict, explain, and simulate heterogeneous therapeutic response across pharmacogenomic, single-cell, spatial, and patient contexts?

## Working rule

Use new computational methods as instruments for answering biological or translational questions. A new architecture is not required if an existing method enables a previously unresolved question to be tested rigorously.

## Frontier radar

Track:

- drug-response prediction and resistance
- perturbation prediction and virtual cells
- treatment-conditioned latent transitions
- flow matching and diffusion
- optimal transport
- causal and disentangled representation learning
- foundation models
- zero-shot and out-of-distribution generalization
- mechanism-aware evaluation
- knowledge-guided and graph models
- dose-time dynamics
- multimodal response modeling
- single-cell and spatial response
- uncertainty and active learning
- digital twins and counterfactual treatment modeling

## Idea-generation loop

`paper / method / dataset` -> `paper card` -> `gap` -> `reusable idea` -> `biological application` -> `cheapest discriminating test` -> `pilot` -> `project` -> `manuscript`

## Required feasibility gate

Before substantial coding, every candidate project must specify:

1. Problem
2. Gap
3. Data
4. Method
5. Validation
6. Biological contribution

## September 2026 priority

Prioritize a project that can reach a complete reproducible analysis and manuscript-ready result set quickly. Journal acceptance or publication timing is external and cannot be guaranteed.

## Structure

- `paper-cards/` — one structured card per important paper
- `idea-cards/` — candidate research ideas derived from papers and datasets
- `frontier-map.md` — live map of methods and emerging research directions
- `projects/` — promoted ideas with concrete analysis plans
